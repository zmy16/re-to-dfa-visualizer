followpos · rilis 1

Regular expression menjadi DFA, tanpa NFA perantara.

Ekspresi diubah menjadi syntax tree, setiap daun diberi nomor posisi, lalu followpos menentukan transisi DFA secara langsung. Setiap tahap ditampilkan agar hasilnya bisa diperiksa, bukan hanya diterima.

LANGKAH 1

Ekspresi dan preprocessing

Alfabet bebas: huruf, angka, atau simbol tunggal. Operator: | (atau), * (Kleene star), tanda kurung, dan E untuk string kosong. Tulis \ di depan karakter bila ingin memakainya sebagai simbol literal.

REFERENSI

Aturan yang dipakai

Preprocessing
Konkatenasi eksplisit disisipkan pada pasangan operand berurutan, lalu ekspresi diaugmentasi menjadi (r)•#. Penanda # menutup pohon dan menandai state penerima.
nullable, firstpos, lastpos
Daun: nullable = false, firstpos = lastpos = {i}. Or menggabungkan kedua anak. Cat memakai anak kanan hanya bila anak kiri nullable, dan sebaliknya untuk lastpos. Star selalu nullable dan mewarisi himpunan anaknya.
followpos
Pada node cat, setiap posisi di lastpos anak kiri menerima seluruh firstpos anak kanan. Pada node star, setiap posisi di lastpos badan menerima seluruh firstpos badan. Tidak ada aturan lain.
Konstruksi DFA
State awal adalah firstpos(root). Untuk tiap state dan tiap simbol alfabet, gabungkan followpos dari posisi yang memuat simbol itu; gabungan tak kosong menjadi transisi dan, bila baru, menjadi state berikutnya. State yang memuat posisi # bersifat menerima.
Batas rilis ini
Konstruksi langsung tidak menjamin jumlah state minimum, jadi minimisasi DFA belum termasuk. Sintaks epsilon, escape operator, dan larangan simbol # serta • sebagai input masih menunggu keputusan pada spec.md.
